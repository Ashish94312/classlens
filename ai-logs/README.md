# AI interaction history

The challenge asks for the prompts and conversations from the AI assistants used during research, development and debugging. This folder holds them.

| Path | Contents |
|---|---|
| `DECISIONS.md` | Running log: what was asked, what the AI proposed, what was accepted or rejected, and why |
| `sessions/` | Redacted exports of Claude Code sessions, generated by `scripts/export_ai_log.py` |

## Redaction rules

Applied before anything lands here:

- Tool outputs are dropped. They can contain transcript text, participant names, or video frames.
- Teacher and student names → `[TEACHER]` / `[STUDENT]` (names come from a local, git-ignored `redact_names.txt`).
- Email addresses, API keys / tokens and absolute home-directory paths are removed.
- Recordings are referred to only by batch id (e.g. `B491`) and quality label.
